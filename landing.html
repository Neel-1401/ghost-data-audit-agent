    Features

    Everything a deletion audit has to check

    Workflow statuses are claims. Ghost Data Audit checks the actual evidence, system by system, at the moment the audit applies to.

    Identity resolution

    Matches current and historical emails, phone numbers, names and email hashes, so a request from an old address still finds every record.

    Multi-format evidence

    Reads SQL snapshots, JSON bundles, service logs, PDFs and admin-console screenshots, and ties each record to the person through grounded identifiers.

    Replica and sync drift

    Compares primary, regional and failover replicas and spots active connectors that copy deleted data back downstream.

    Restore-risk blocking

    Flags backups that could restore the person's data and puts blocking the restore ahead of any record change in the plan.

    Policy engine

    Applies your deletion rules per data category: delete, redact, anonymize or retain, including account tombstones that keep only a stable reference.

    Find → Fix → Check plans

    Every incomplete deletion gets evidence-backed findings, a safely ordered remediation plan and the verification checks that must pass afterwards.

    How it works

    From request to proof in four steps

    An LLM handles the language and the screenshots. Everything that decides the answer is deterministic and reproducible.

    1. 01

      Classify the request

      Decides whether the message, in any language, actually authorises deletion. Access, export and opt-out requests are not deletions.

      LLM + rule fallback
    2. 02

      Resolve identity

      Rebuilds the person's current and past identifiers and links their account from evidence and deletion activity.

      Deterministic
    3. 03

      Reconstruct state at audit time

      Uses only evidence visible at the audit cutoff and never cites a file captured after it. Reported statuses are treated as claims.

      Deterministic
    4. 04

      Plan remediation and verification

      Applies the policy to each record and outputs ordered findings, fixes and checks with evidence IDs.

      Deterministic
